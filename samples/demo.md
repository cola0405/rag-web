# RAG Web 知识库使用说明

## 创建知识库

在 Web 界面左侧填写名称，选择 Embedding 模型后点击「创建」。
默认情况下使用本地哈希向量 local-hash，不需要填写任何 API Key。
也可以在页面右上角的「Embedding 模型管理」里添加云端服务，获得真实语义召回能力。

## 上传文档

支持 txt、markdown、pdf、csv、json。上传后文档会先被解析成纯文本，
再按知识库配置的 chunk_size 切分成文本块，块与块之间保留 chunk_overlap 个字符的重叠。
Markdown 文件按标题层级分块，其他文件按段落、句子递归切分。

## 检索原理

检索采用混合策略：先分别做 FAISS 稠密向量检索和 SQLite FTS5 的 BM25 稀疏检索，
再把两路结果做 min-max 归一化加权融合，稠密权重默认为 0.9，稀疏检索的分数按知识库分组归一化。
RRF 只作为融合分数相同时的稳定排序依据。最后按 top_m_final 截断，并拼成可直接给大模型使用的上下文。

## 注意事项

同一个知识库创建后不要更换 Embedding 模型，因为 FAISS 索引的向量维度在初始化时就固定了。
删除文档会同时清理元数据记录、文本块、向量和原始文件。
